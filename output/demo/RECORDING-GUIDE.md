# Workshop Relay — record your own demo

The Open Agentic Web Challenge asks for a public YouTube demonstration under two minutes in which the entrant explains the project. The explanation must not be AI generated. Use your own words and voice; this is a visual cue sheet, not a narration script.

Live app: https://dcontessa.github.io/workshop-relay/
Source: https://github.com/dcontessa/workshop-relay

Before recording: use desktop Chrome or Edge with WebGPU, run Browser AI once to download/cache the model, and reset the example. You may show the saved real evidence while describing the architecture. Keep the full video around 1 minute 45 seconds.

| Time | Show | Explain in your own words |
| --- | --- | --- |
| 0:00–0:15 | Initial workshop brief and RM4,300 plan | The coordination problem and whom this helps |
| 0:15–0:30 | Provider websites and their manifest/network links | Independent websites publish portable agents and catalogues |
| 0:30–0:50 | Consent screen, then a completed agent run | The approved sources; models run locally; peer networks execute in the caller browser |
| 0:50–1:05 | Activity & evidence | Actual model responses and both peer calls; source-backed costs |
| 1:05–1:25 | Saved plan, then simulated venue cancellation | The replacement is RM4,700, RM400 more, preserving capacity/accessibility/date |
| 1:25–1:40 | Budget RM4,500 → no match | The RM200 shortfall and why constraints are never silently relaxed |
| 1:40–1:50 | Return to initial plan or repo | What you built/learned; all providers fictional; saving is planning, not booking |

If a live agent run takes too long, edit out the wait while keeping the consent and the actual completed evidence. Do not imply edited time is real-time latency. Do not imply the manual planner is LLM-generated.

After recording: export a video shorter than 2:00, upload it to YouTube with public visibility, and provide its URL for the Devpost video field. A silent walkthrough or synthetic voice alone does not fulfill this entrant explanation requirement.

A silent screen recording is available at `planner-walkthrough-silent.mp4`. It demonstrates the provider directory, consent, reviewed save, cancellation recovery and budget failure. It does not include a live agent run or narration; use the separately saved real execution evidence when explaining the agent architecture. It is a supporting clip, not a finished qualifying entry video.
